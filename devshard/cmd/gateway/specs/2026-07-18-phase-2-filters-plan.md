# Gateway Phase 2: Filters + Golden Parity — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The `cmd/gateway/filters` package — the complete request/response boundary with a single registration table and model profiles — proven byte-for-byte equivalent to devshardctl's pipeline by committed golden files.

**Architecture:** Phase 2 of 9 (spec §13, §15.1). The old pipeline (`cmd/devshardctl/request_filters*.go`, `paramvalidators/`, `messagevalidators/`) is the reference oracle: a build-tagged generator test in the old package runs a curated corpus through `normalizeChatRequestForAuthAndLimits` once and commits goldens; the new package must reproduce them exactly. Old code is readable in-tree — tasks port semantics from named old files, and the goldens mechanically enforce fidelity.

**Tech Stack:** Go 1.24.2, module `devshard`; std `testing`; no new dependencies. Consumes Phase 1's `config` only for shared constants where noted; filters itself stays dependency-light (spec §4: `filters` depends only on `config`).

## Global Constraints

- All Phase 1 Global Constraints remain in force (naming, error style, `-race -count=1`, gofmt/vet clean before every checkpoint, no `os.Getenv` outside `env/`, no mutable package-level state — the rule TABLE is an immutable package `var`, allowed like Phase 1's `migrations`).
- `cmd/devshardctl` may be touched by exactly ONE new file: `goldengen_test.go` with build tag `goldengen` (spec §3 non-goal exception). Nothing else in the old package changes.
- **Behavior parity is the merge bar**: every golden must match byte-for-byte. An intentional divergence requires Daniil's explicit approval and a regenerated golden in the same change with justification — there are no "small" silent differences.
- The new pipeline must end in `json.Marshal` of a `map[string]any` document (Go sorts map keys — this is what makes byte-for-byte parity achievable against the old `ChatRequestDocument.Marshal`, `request_filters_parameters.go:219-224`).
- Old-package REJECTION responses are part of parity: HTTP status + exact message text (`chatRequestFilterError`, `request_filters.go:27-68`; whitelist text from `unsupportedChatParameterMessage`, `request_filters.go:284-286`).
- Model scoping is expressed exactly ONE way in the new package (profiles) — porting any of the old three conventions verbatim is a defect.
- Capture-on-reject stays OUT of filters (api-phase concern): filters returns errors; it never writes files.
- **Commits are made by Daniil**: executor skips commit steps; single user commit at phase end (same working agreement as Phase 1).

## Corpus / golden format (fixed contract for Tasks 1–8)

Corpus case (one JSON file per case, name = filename):

```json

  "admin": false,
  "default_max_tokens": 3072,
  "max_tokens_cap": 4096,
  "body": { "model": "...", "messages": [ ... ], "temperature": 3.5 }

```

Golden (same basename under goldens/):

```json
{"status": "ok", "body_base64": "<base64 of the exact normalized body bytes>"}
{"status": "rejected", "http_status": 400, "message": "<exact error text>"}
```

`body_base64` (not embedded JSON) so golden files can never be reformatted into lies by editors/linters. Case filename prefix groups parity subsets by task: `basic_`, `arrays_`, `tokens_`, `schema_`, `profile_`, `messages_`, `whitelist_`, `structure_`.

```go
package main

import (
	"encoding/base64"

// TestGenerateFilterGoldens runs every corpus case through the OLD pipeline and
// writes the golden the NEW cmd/gateway/filters package must reproduce
// byte-for-byte. Run manually: go test ./cmd/devshardctl/ -tags goldengen -run TestGenerateFilterGoldens -count=1
type goldenCorpusCase struct {
	RoutedModel      string          `json:"routed_model"`
	Admin            bool            `json:"admin"`
	DefaultMaxTokens uint64          `json:"default_max_tokens"`
	MaxTokensCap     uint64          `json:"max_tokens_cap"`
	Body             json.RawMessage `json:"body"`
}

func TestGenerateFilterGoldens(t *testing.T) {
	corpusDir := filepath.Join("..", "gateway", "filters", "testdata", "corpus")
	goldensDir := filepath.Join("..", "gateway", "filters", "testdata", "goldens")
	entries, err := os.ReadDir(corpusDir)
	if err != nil {
		t.Fatalf("reading corpus dir: %v", err)
	}
	if err := os.MkdirAll(goldensDir, 0o755); err != nil {
		t.Fatalf("creating goldens dir: %v", err)
	}
	generated := 0
	for _, entry := range entries {
		if entry.IsDir() || !strings.HasSuffix(entry.Name(), ".json") {
			continue
		}
		raw, err := os.ReadFile(filepath.Join(corpusDir, entry.Name()))
		if err != nil {
			t.Fatalf("%s: %v", entry.Name(), err)
		}
		var corpusCase goldenCorpusCase
		if err := json.Unmarshal(raw, &corpusCase); err != nil {
			t.Fatalf("%s: parsing case: %v", entry.Name(), err)
		}
		limits := outputTokenLimits{DefaultMaxTokens: corpusCase.DefaultMaxTokens, MaxTokensCap: corpusCase.MaxTokensCap}
		normalizedBody, _, err := normalizeChatRequestForAuthAndLimits(corpusCase.Body, corpusCase.Admin, limits, corpusCase.RoutedModel)
		var golden map[string]any
		if err != nil {
			golden = map[string]any{
				"status":      "rejected",
				"http_status": chatRequestErrorStatus(err, 400),
				"message":     err.Error(),
			}
		} else {
			golden = map[string]any{
				"status":      "ok",
				"body_base64": base64.StdEncoding.EncodeToString(normalizedBody),
			}
		}
		encoded, err := json.MarshalIndent(golden, "", "  ")
		if err != nil {
			t.Fatalf("%s: encoding golden: %v", entry.Name(), err)
		}
		if err := os.WriteFile(filepath.Join(goldensDir, entry.Name()), append(encoded, '\n'), 0o644); err != nil {
			t.Fatalf("%s: writing golden: %v", entry.Name(), err)
		}
		generated++
	}
	t.Logf("generated %d goldens", generated)
	if generated == 0 {
		t.Fatal("no corpus cases found — corpus must exist before generating")
	}
}
```

```go
package filters

import (
	"bytes"
	"encoding/base64"
	"encoding/json"
	"os"
	"path/filepath"
	"strings"
	"testing"
)

type parityCase struct {
	RoutedModel      string          `json:"routed_model"`
	Admin            bool            `json:"admin"`
	DefaultMaxTokens uint64          `json:"default_max_tokens"`
	MaxTokensCap     uint64          `json:"max_tokens_cap"`
	Body             json.RawMessage `json:"body"`
}

type parityGolden struct {
	Status     string `json:"status"`
	BodyBase64 string `json:"body_base64"`
	HTTPStatus int    `json:"http_status"`
	Message    string `json:"message"`
}

// TestGoldenParity is the phase's merge bar: every corpus case must reproduce
// the old pipeline's exact bytes (ok) or exact status+message (rejected).
func TestGoldenParity(t *testing.T) {
	corpusEntries, err := os.ReadDir(filepath.Join("testdata", "corpus"))
	if err != nil {
		t.Fatalf("reading corpus: %v", err)
	}
	if len(corpusEntries) == 0 {
		t.Fatal("corpus is empty")
	}
	for _, entry := range corpusEntries {
		if entry.IsDir() || !strings.HasSuffix(entry.Name(), ".json") {
			continue
		}
		t.Run(strings.TrimSuffix(entry.Name(), ".json"), func(t *testing.T) {
			rawCase, err := os.ReadFile(filepath.Join("testdata", "corpus", entry.Name()))
			if err != nil {
				t.Fatalf("reading case: %v", err)
			}
			var testCase parityCase
			if err := json.Unmarshal(rawCase, &testCase); err != nil {
				t.Fatalf("parsing case: %v", err)
			}
			rawGolden, err := os.ReadFile(filepath.Join("testdata", "goldens", entry.Name()))
			if err != nil {
				t.Fatalf("reading golden (regenerate with -tags goldengen in devshardctl): %v", err)
			}
			var golden parityGolden
			if err := json.Unmarshal(rawGolden, &golden); err != nil {
				t.Fatalf("parsing golden: %v", err)
			}

			result, err := NormalizeRequest(testCase.Body, Options{
				Admin:            testCase.Admin,
				DefaultMaxTokens: testCase.DefaultMaxTokens,
				MaxTokensCap:     testCase.MaxTokensCap,
				RoutedModel:      testCase.RoutedModel,
			})

			switch golden.Status {
			case "ok":
				if err != nil {
					t.Fatalf("old pipeline accepted, new rejected: %v", err)
				}
				wantBody, decodeErr := base64.StdEncoding.DecodeString(golden.BodyBase64)
				if decodeErr != nil {
					t.Fatalf("decoding golden body: %v", decodeErr)
				}
				if !bytes.Equal(result.Body, wantBody) {
					t.Fatalf("body mismatch\n old: %s\n new: %s", wantBody, result.Body)
				}
			case "rejected":
				if err == nil {
					t.Fatalf("old pipeline rejected (%d %q), new accepted: %s", golden.HTTPStatus, golden.Message, result.Body)
				}
				if got := ErrorStatus(err, 400); got != golden.HTTPStatus {
					t.Fatalf("status mismatch: old %d, new %d (%v)", golden.HTTPStatus, got, err)
				}
				if err.Error() != golden.Message {
					t.Fatalf("message mismatch\n old: %q\n new: %q", golden.Message, err.Error())
				}
			default:
				t.Fatalf("golden has unknown status %q", golden.Status)
			}
		})
	}
}
```
